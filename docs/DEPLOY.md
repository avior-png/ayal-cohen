האתר **דורש שרת Node**. מערכת הניהול קוראת עוגיות וטופס יצירת הקשר הוא
Server Action, ושניהם לא קיימים באחסון סטטי. GitHub Pages, S3 או Netlify

## מסלול מהיר: קישור ל-QA בחמש דקות

**בלי מסד נתונים.** כל העמודים הציבוריים נבנים מהזרעים שב-`content/site.ts`
ולא מהמסד, ולכן הם עולים גם בלי `DATABASE_URL`. נבדק: כל עשרת העמודים
הציבוריים מחזירים 200 בלי מסד.

1. **vercel.com** → Add New → Project → Import Git Repository → בחירת המאגר
2. Framework: Next.js (מזוהה אוטומטית). **בלי לגעת בשום הגדרה.**
3. Deploy
4. ⚠️ **Settings → Git → Production Branch → `claude/trusting-rubin-a6o6ca`**
   → Redeploy

הקישור שמתקבל הוא הקישור ל-QA.

### ⚠️ שלב 4 הוא לא אופציונלי

Vercel פורס את **ברירת המחדל של המאגר**, וברירת המחדל כאן היא
`claude/github-connection-check-k3prb4` — הענף שאליו הועלו קובצי הזיפ,
ובו התבנית הבסיסית בלבד. **כל עבודת האתר יושבת על
`claude/trusting-rubin-a6o6ca`.** בלי שלב 4 הקישור ל-QA יציג אתר אחר.

שתי דרכים לפתור את זה לתמיד, ושתיהן עדיפות על תיקון בהגדרות Vercel:
- **מיזוג** `claude/trusting-rubin-a6o6ca` אל ענף ברירת המחדל, או
- **החלפת ענף ברירת המחדל** במאגר ל-`claude/trusting-rubin-a6o6ca`
  (GitHub → Settings → Branches → Default branch)

אגב: שלושת קובצי הזיפ וה-PNG שהועלו לשורש ענף ברירת המחדל אינם חלק
מהאתר ואפשר למחוק אותם.

  `production` ומחזיר ‎`Disallow: /`‎ לכל הבוטים. בלי זה עותק QA של אתר

  מ-‎`VERCEL_URL`‎ בפריסות Vercel, ולכן בכתובת ה-QA כל ההפניות מצביעות
  לעצמה ולא לדומיין שעוד לא באוויר.

## מסלול מלא: פרודקשן

1. **neon.tech** → Create project → העתקת ה-Connection string
2. ב-Vercel: Settings → Environment Variables
   | משתנה | ערך |
   |---|---|
   | `DATABASE_URL` | ה-Connection string מ-Neon |
   | `SESSION_SECRET` | מחרוזת אקראית ארוכה (`openssl rand -base64 32`) |
   | `NEXT_PUBLIC_SITE_URL` | הדומיין הסופי, **רק** כשמחברים דומיין אמיתי |
3. Redeploy
4. הרצת המיגרציות והזרעים פעם אחת מול המסד:
   ```
   DATABASE_URL="..." npx prisma migrate deploy
   DATABASE_URL="..." npm run db:seed
   ```
5. Settings → Domains → חיבור הדומיין

> **תת-נתיב.** אם האתר לא יושב בשורש הדומיין, יש להעביר `BASE_PATH=/הנתיב`
> בזמן הבנייה. בשורש — לא צריך כלום.

> ⚠️ **אחסון תמונות.** התמונות שהלקוח מעלה נשמרות ב-`public/uploads/` על
> הדיסק, וב-Vercel הדיסק אינו נשמר בין פריסות. לפני שלקוח מעלה תמונות יש
> לעבור לאחסון חיצוני (Vercel Blob / S3) — הכתיבה מרוכזת ב-`lib/media.ts`.

## מה לומר לבודקת מראש

אלה **פערי תוכן מוכרים**, לא באגים. עדיף שהיא תדע מראש מלדווח עליהם:

| | |
|---|---|
| טלפון | `03-000-0000` — Placeholder |
| אימייל | `office@el-hahon.co.il` — Placeholder |
| ח.פ. | `000000000` — Placeholder |
| קישורי הרשתות בפוטר | `#` — האייקונים אמיתיים, הקישורים לא |
| שתי תשובות בשאלות הנפוצות | מסומנות `needsSignoff` — ממתינות לאישור איל |
| כל תצלומי הסצנות | המחשות. אין להציג את האנשים כלקוחות או כאיל |

**כן כדאי שתבדוק:** קריאוּת ונגישות (כולל ניווט מקלדת ומצבי פוקוס),
התנהגות ב-390px / 768px / 1440px, ניסוח וטעויות כתיב, נכונות הטענות
המקצועיות, וכל דבר שנראה שבור.

⚠️ **וההערה החשובה:** הקופי בתחום הזה מפוקח על ידי רשות שוק ההון. אין
באתר הבטחת תשואה, סכום קצבה או חיסכון במס, וכל דוגמה מסומנת כהמחשה —
אבל **אישור רגולטורי או משפטי לקופי טרם התקבל**, וזה חייב לקרות לפני
עלייה לדומיין האמיתי, לא אחריה.
